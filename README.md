# 金融講座 テスト対策アプリ

`index.html` をブラウザで開くだけで使える、サーバー不要の学習アプリです。

## 収録内容

- 11科目・計200問（○×・四択）。経済情報、外国為替、株式、投資信託、iDeCo、行動ファイナンスに加え、金融市場、つみたて投資、資産形成とマネープラン、債券、公的年金を収録。
- 正誤表示と資料に基づく解説
- ランダム出題、進捗バー、セッションごとのスコア
- 間違えた問題だけの復習
- 学習履歴・テーマ設定のブラウザ内保存（localStorage）
- スマートフォン対応、ダークテーマ

## 問題を追加するには

`questions.js` の `QUESTIONS` 配列に、次の形式で追加します。

```js
{ id:'unique-id', category:'economy', type:'choice', question:'問題文', choices:['選択肢1','選択肢2'], answer:0, explanation:'解説', source:'資料名' }
```

○×問題は `choices:['○','×']` とし、`answer:0` を○、`answer:1` を×にします。

PDF原本を確認できるようになった科目から、`QUIZ_CATEGORIES` の `available` を `true` に変更して問題を追加してください。
